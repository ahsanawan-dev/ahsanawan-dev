### 01 — VELORA Motors

[![VELORA Motors homepage with its featured car](https://raw.githubusercontent.com/ahsanawan-dev/velora-car-showroom/main/docs/preview.jpg)](https://ahsanawan-dev.github.io/velora-car-showroom/)

A fictional automotive showroom with a hosted PHP + MySQL collection, admin car management, draft/publish controls, and a stored enquiry workflow. The original frontend includes a fullscreen photo gallery.

- **Built with:** HTML, CSS, JavaScript, PHP and MySQL.
- **Implementation:** coordinated car and angle selection, dynamic photo updates, and keyboard controls in the gallery.
- **Explore:** [PHP + MySQL demo](https://velora-ahsan.great-site.net/manager/public/) · [Frontend gallery](https://ahsanawan-dev.github.io/velora-car-showroom/) · [Code & setup guide](https://github.com/ahsanawan-dev/velora-car-showroom)

**PHP + MySQL extension:** [Showroom Manager](https://github.com/ahsanawan-dev/velora-car-showroom/tree/main/manager) adds admin login, car management, draft/publish controls, and an enquiry inbox.
